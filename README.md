# Biliardo3D
Repository per il progetto finale di FCG


# Build delle tappe

cmake -B build && cmake --build build

# Come lanciare gli eseguibili

All'interno della cartella build ./Tappa(numero Tappa)

# Comandi

## Tappa01

Drag con click destro: rotazione scena

Left Control + movimento mouse: zoom

Left Alt + movimento mouse: dolly

## Tappa07

Tasto A senza movimento biglie: Modalità visuale: AIM

Tasto T: Modalità visuale: TOP

Tasto F senza movimento biglie: 
Modalità visuale: FREE

Funzione provvisoria solo di questa tappa: Barra spazziatrice: applica una velocità costante alla biglia bianca

## Tappa08

Drag con click sinistro: caricamento tiro
Rilascio click sinistro: tiro

## Tappa11

Durante il riposizionamento della biglia bianca dopo un fallo:

Freccette direzionali: spostare la biglia bianca

ENTER: Conferma posizione biglia bianca
